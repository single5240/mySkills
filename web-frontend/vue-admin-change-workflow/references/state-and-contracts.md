# 状态与接口检查

按变更涉及的部分读取，不把全文变成每次修改的强制清单。

## 响应式与异步生命周期

- 为筛选条件、分页、选中项、编辑草稿和服务端快照划清所有者；编辑草稿不能直接改列表对象。切换记录或重开弹窗时清除旧校验和残留数据。
- 派生值使用无副作用的 `computed`，副作用才使用 watcher。注意从 `reactive` / Pinia state 解构造成的响应性丢失；遵循当前版本支持的响应式解构语义，不机械改写所有解构。
- 选择 `ref` / `reactive` / `shallowRef` 看更新方式和对象特性。外部实例或大体积只整体替换的数据可考虑浅层响应式，不将“原始值一律 shallowRef”作为性能规则。
- 对查询 A 慢、B 快的情况，确定采用取消、请求序号或其他现有策略，保证 A 的结果、错误及 finally 都不会修改 B 的状态。请求取消是交互分支，不当作业务失败弹窗。
- 对提交设置执行期互斥，检查成功、失败和取消都能恢复交互；不要用前端按钮禁用代替服务端幂等，也不因超时就认定写操作未发生。
- 组件卸载、watcher 失效和路由参数变化时，清理实际拥有的轮询、事件监听、订阅和请求。`KeepAlive` 场景核实停用/激活语义；共享连接不能由单一页面擅自关闭。
- 使用版本适用的清理 API；如采用 `onWatcherCleanup`，核对 Vue 版本与同步注册限制，不在 await 后才注册。

## API 与交互契约

- 从后端定义、契约文档或可核实的现有实现确认方法、路径、参数、业务码和响应形状；不能用类型断言修补不明契约。缺少后端时明确假设或占位状态。
- 检查 ID 精度、字符串编号前导零、金额/时长单位、时区、枚举、空值及分页边界；保持 0、false、空串与缺失值的业务区别。
- 分页查询和搜索重置同步处理；删除最后一页最后一条、筛选后已选 ID、弹窗切换对象等场景按业务清除或保留状态。
- 列表错误、空列表、首屏 loading 和后台刷新是不同状态；保留输入与可恢复路径，避免请求失败被空态吞掉。错误提示复用请求封装，不重复弹出。
- 下载检查业务错误与文件响应，上传沿用公共校验和失败反馈；创建的 object URL 在使用结束后释放。不要让错误 JSON 被保存成正常业务文件。

## 权限与客户端安全

- 跟踪登录状态、守卫、动态路由、菜单和按钮权限；退出及切换账号时不能残留上个用户的路由或敏感状态。异步失败也必须终止 loading / 进度反馈。
- 前端权限仅辅助交互，服务端须核验每次操作及对象归属。不得扩大白名单、伪造角色或隐藏错误以绕过权限。
- 检查客户端环境变量、打包资源和日志不会泄露服务端秘密；`VITE_*` 不是保密机制。加密请求也不能替代 TLS、服务端授权或密钥隔离。
- 不把不可信 HTML 直接送入 `v-html`，不随意执行服务端返回脚本。使用现有可信渲染/净化机制，涉及策略变化时说明兼容与风险。

## 设备控制与外部副作用

先核实当前工程链路。若约定“浏览器 HTTP → 后端 MQTT → 设备”，保持后端拥有凭据、协议转换、重试与应答关联；不推广为所有 Vue 项目的固定架构。

明确在线/离线、请求提交、后端受理、设备应答、执行成功和未知状态的证据来源；超时后查询或恢复方式依后端契约，不自动重发充值、次数修改等可能重复生效的命令。

检查设备标识、参数范围、确认交互、提交互斥、权限和审计关联。写前说明测试对象与预期副作用，仅在已授权设备和环境中联调；Mock 只证明交互或状态逻辑。
