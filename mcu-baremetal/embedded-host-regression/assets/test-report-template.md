# 测试报告模板

复制后按风险裁剪；“待填写／未执行”是有意保留的字段，不代表通过。

## 1. 身份与依据

- 报告编号、版本，执行时间及时区：待填写
- 执行者／自动化任务：待填写
- 项目、模块、实际路径：待填写
- 被测 Commit、未提交状态、源码／配置哈希：待填写
- 测试脚本版本／哈希：待填写
- 需求、协议或缺陷依据及版本：待填写

## 2. 目标与范围

说明修改、待验证行为、实际生产源码范围、旧功能和不覆盖项。通过条件在执行前确定，不按结果倒推。

## 3. 环境与模型

- 主机系统、编译器及版本：待填写
- 目标芯片、原工具链、关键宏／参数：待填写
- 时间、GPIO、通信及存储替身：待填写
- 故障模型、注入点、随机种子：待填写
- 未建模的中断、DMA、硬件与目标 ABI：待填写

## 4. 用例与实际结果

| ID | 需求／场景 | 前提与输入 | 预期 | 实际观察 | 状态 | 证据 |
| --- | --- | --- | --- | --- | --- | --- |
| 待填写 | 待填写 | 待填写 | 待填写 | 未执行 | NOT RUN | 待填写 |

计划、执行、PASS／FAIL／BLOCKED／NOT RUN／N/A 数量待填写。用例、测试组、断言、设备数量分别说明；未知数量不能填 0。

## 5. 执行证据

- 完整命令、返回码：待填写
- 原始日志、summary.json与源码身份：待填写
- 重放所需输入、配置和种子：待填写
- 长期归档位置／可访问附件：待填写

## 6. 原工具链与硬件验证

| 层级 | 状态 | 结果与证据 |
| --- | --- | --- |
| 目标编译／链接 | 未执行 | 待填写错误、告警、资源和链接边界 |
| IDE 最终烧录输出处理（适用时） | 未执行 | 待填写 |
| 实板功能、时序与通信 | 未执行 | 待填写硬件版本及条件 |
| 真实掉电／低功耗等专项 | 未执行 | 待填写或说明不适用理由 |

## 7. 缺陷、限制与结论

- 未解决问题、未执行原因、模型局限和影响：待确认
- 主机逻辑结论：待确认
- 原工具链结论：待确认
- 实板结论：待确认
- 下一阶段建议、必要条件、确认人和日期：待填写

没有证据时不写“无缺陷”，不能仅凭主机 PASS 自动给出可量产／可发布结论。
