# answer-me-with-html（v0.4.12）中文整理

来源：https://github.com/QingYunA/answer-me-with-html （MIT 协议，提交 ad242ca，2026-10-06）

## 它是干什么的
让 AI 助手把复杂回答做成一页可视化 HTML 讲解页。模型只写一份扩展 Markdown 草稿，
自带的 `scripts/am.mjs`（单文件、无依赖，需要 Node.js 20+）负责排版、配色、暗色模式和图表坐标。
不用手写 HTML / CSS / SVG。

## 什么时候触发
只在用户当前这条消息里明确要求时使用：
- 调用 `/answer-me-with-html`
- 明确要求 HTML 讲解页、可视化讲解，或讲解视频（“做个视频”）
- 要求修改本技能的设置或触发策略

普通解释、架构说明、对比、审查和长回答不要主动调用。

## 用法
```bash
node scripts/am.mjs render - <<'AM_EOF'
---
title: 标题
---
## A 面板标题
```flow
A -> B: 标签
```
AM_EOF
```
成功输出 `✓ <路径>`；报错 `✗ L<行号>` 会附正确示例；`STE n warnings` 是写作规范提醒。
只改一个面板用 `am patch page.html --panel "面板标题"`。

## 组件速查
| 信息形状 | 组件 |
|---|---|
| 架构、连接关系、决策分支 | `flow` |
| 多方按时间收发消息（协议、时序） | `sequence` |
| 层级、目录、分类 | `tree` |
| 历史、阶段 | `timeline` |
| 数值和上限 | `limits` |
| 逐词批注 | `annot` |
| 元数据标题块 | `kv` |
| 结论、警告 | `callout info/ok/warn/err` |
| 多维对比 | Markdown 表格（状态列写 ok / no / warn） |

主题：`auto`（默认）、`blueprint`、`shadcn`、`paper`、`3b1b`。模板：`sheet`（一屏总览，默认）、`doc`（线性阅读）。

## 设置与维护
- `am config` 查看设置；`am config set <key> <value>` 修改（open、theme、mode、style、voice、update_check）
- `am clean --dry-run` 先看要清理多少，再 `am clean`
- 生成的页面在 `~/.answer-me-with-html/` 下

## 讲解视频（可选）
`am video - --no-open`，草稿里以 `>` 开头的行是旁白，一个 `##` 是一个场景。
加 `--mp4` 导出视频文件，需要 Chrome、ffmpeg 和 Node.js 22+。

## 安装位置
把整个 `answer-me-with-html` 文件夹放到对应目录：
- Claude Code：`%USERPROFILE%\.claude\skills\answer-me-with-html`
- Cursor / Codex 等：`%USERPROFILE%\.agents\skills\answer-me-with-html`（Cursor 也读 `%USERPROFILE%\.cursor\skills`）
- 或者用官方命令：`npx -y skills add QingYunA/answer-me-with-html -g -y -a <agent 名>`
同一个 agent 只装一种方式，插件和 skill 同时装会重复加载。
