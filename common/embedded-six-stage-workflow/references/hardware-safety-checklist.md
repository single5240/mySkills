# 嵌入式硬件与并发安全检查清单 (Hardware & Concurrency Safety Checklist)

在设计（Design）、执行（Execute）与验证（Verify）阶段，针对以下高风险场景逐项核对：

## 1. 中断 (ISR) 与并发共享数据
- [ ] **ISR 短小确定**：ISR 仅执行状态读取、标志清除、时间敏感位操作或最小数据搬运；严禁在 ISR 中调用阻塞延时、Flash 擦写、动态内存分配、长循环或耗时日志（如 `printf`）。
- [ ] **`volatile` 与原子性**：主循环、ISR、DMA 共享的标志与计数器必须声明 `volatile`；但 `volatile` 不保证复合操作（读-改-写）或多字节数据的原子性，需采用单生产者/单消费者双缓冲发布协议或极短临界区。
- [ ] **抢占优先级明确**：新增中断需核对 NVIC 分组（如 `NVIC_PriorityGroup_4`）及与最高优先级采样/定时中断的抢占关系。

## 2. DMA 与外设总线安全
- [ ] **缓冲区生命周期**：DMA 缓冲区严禁分配在栈（Stack）上，必须使用静态内存并满足对齐与数据宽度要求；在 `IsBusy() == false` 前，调用方绝不可覆写该缓冲区。
- [ ] **DMA 完成 != 外设发送完成**：如 SPI DMA TX/RX 完成中断触发时，移位寄存器可能仍在发送最后一位；在拉高 CS 片选、切换 SPI 数据宽度或关闭外设前，必须在主循环确认外设 `BUSY` 标志已清除。
- [ ] **外设单一所有者**：运行期间禁止用另一套初始化覆盖正在工作的 SPI/I2C/UART 的时钟极性、字长、DMA 映射或复用引脚。

## 3. 定时器、延时与看门狗 (IWDG/WDT)
- [ ] **无符号 Tick 回绕安全**：所有超时与非阻塞延时均使用无符号差值 `(uint32_t)(now_tick - start_tick) >= timeout_ ticks`，禁止使用 `now_tick >= target_tick` 以防溢出死等。
- [ ] **看门狗喂狗纪律**：仅在主循环唯一调度点喂狗，严禁在定时器 ISR 或底层驱动死等循环中喂狗。
- [ ] **看门狗窗口约束**：`IWDG_Init()` 置于所有阻塞初始化之后；运行期的耗时操作（如大块擦写、刷屏）必须拆分为非阻塞状态机，确保主循环单轮耗时远小于看门狗超时窗口。

## 4. GPIO、低功耗与复用引脚
- [ ] **上电防误动作**：GPIO 输出初始化时，必须**先写入安全电平数据寄存器，再配置方向为输出模式**，防止驱动功放、电机或发热器件产生上电毛刺。
- [ ] **分时复用引脚恢复**：若同一引脚分时复用（如按键 `KEY` 与射频 `CSN` 共用），每次通信或扫描后必须恢复端口方向寄存器（如 `TRISx`/输入输出模式）与默认电平。
- [ ] **休眠与唤醒闭环**：进入低功耗前关闭外设功耗（如功放、射频芯片掉电、PWM 关闭）、清理未完成帧状态并清除唤醒中断标志；唤醒后按严格时序恢复时钟与外设接收态。

## 5. 资源受限与工具链约束（ARMCC 5 / XC8 / 8位机）
- [ ] **零动态分配**：禁止使用 `malloc`/`free`、变长数组（VLA）及递归调用；字库与只读查找表必须加 `const` 放入 Flash/ROM。
- [ ] **旧编译器兼容**：在 Keil ARMCC 5 中注意 UTF-8 中文字符串字面量转义；在 XC8 / C90 8位机编译器中局部变量须声明在代码块开头，并严格核算 Flash（words）与 RAM（bytes）余量。
- [ ] **防越界与防除零**：所有通信帧载荷长度、通道位移（如 `1U << ch`）、数组下标、ADC 换算必须显式做范围与边界检查。
